Как открыть архив на GitHub Pages и на uCoz

Сайт нарочно сделан «старым» HTML 4.01: относительные ссылки, табличная вёрстка карточек, один CSS-файл, никаких модулей JavaScript, React и шрифтовых CDN.

Состав архива

  • index.html — главная, все четыре блока;
  • 01-…html … 10-…html — конспекты;
  • style.css — стили;
  • img/ — изображения;
  • smi/ — раздел международных публикаций.

GitHub Pages

  1. Откройте Settings → Pages.
  2. Source: Deploy from a branch.
  3. Branch: main, folder: / (root).
  4. Сайт будет доступен по адресу вида https://логин.github.io/имя-репо/.

uCoz

  1. Загрузите HTML-файлы и style.css в корень.
  2. Папку img загрузите целиком.
  3. Папку smi загрузите целиком.
  4. Кодировка — UTF-8.
