Как открыть архив на GitHub Pages и на uCoz

Сайт нарочно сделан «старым» HTML 4.01: относительные ссылки, табличная вёрстка карточек, один CSS-файл, никаких модулей JavaScript, React и шрифтовых CDN. Так его ест и GitHub Pages, и файловый менеджер uCoz.

Состав архива

  • index.html — главная, все четыре блока;
  • smi.html — раздел «СМИ», реакция международной прессы;
  • 01-…html … 10-…html — конспекты первоисточников;
  • smi-01-…html … smi-08-…html — конспекты публикаций;
  • style.css — стили в той же папке, что и страницы;
  • img/ — фотографии (JPG), на страницах чередуются;
  • favicon.ico — иконка;
  • README.txt — эта же памятка текстом.

Все ссылки относительные: style.css, img/01.jpg, 03-merkel-zeit-2022.html. Не переименовывайте файлы и не разносите их по разным каталогам без правки href.

GitHub Pages

  1. Создайте пустой репозиторий (например, krasnye-linii).
  2. Загрузите содержимое ZIP в корень репозитория — чтобы index.html лежал не во вложенной папке, а сразу в корне.
  3. Settings → Pages → Source: Deploy from a branch → branch main (или master), folder / (root).
  4. Через минуту сайт откроется как https://логин.github.io/имя-репо/.

Если репозиторий называется логин.github.io, архив станет корневым сайтом аккаунта.

uCoz

  1. Панель uCoz → Файловый менеджер (или «Загрузить файл»).
  2. Кодировка: UTF-8. В настройках сайта тоже выберите UTF-8, иначе кириллица «кракозябрами».
  3. Загрузите index.html, остальные .html, style.css, favicon.ico в корень. Папку img загрузите целиком (все JPG внутрь /img/).
  4. Главной сделайте index.html. Если uCoz подменяет главную своим шаблоном — откройте материал по прямому адресу /index.html или вставьте HTML в «страницу сайта» без обёртки движка.
  5. Не включайте «визуальный редактор» поверх этих файлов: он ломает таблицы и кавычки.

Протоколы — обычный HTTP/HTTPS хостинга uCoz, без PHP, без SSI, без AJAX. Страницы печатаются через «Печать» браузера (есть отдельный print-стиль).

Локально, с диска

Распакуйте ZIP и откройте index.html двойным щелчком. Интернет нужен только чтобы перейти по ссылкам на YouTube и Die Zeit.
