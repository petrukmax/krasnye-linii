КРАСНЫЕ ЛИНИИ — архив первоисточников 2007–2024
================================================

Чистый HTML 4.01 + CSS. Без JavaScript, PHP и внешних шрифтов.
Кодировка всех файлов: UTF-8.

Состав
------
index.html     — главная, четыре блока первоисточников
smi.html       — раздел СМИ (международная пресса)
01-…html       — конспекты речей и интервью
smi-0…html     — конспекты газетных и агентских материалов
style.css      — стили (в той же папке)
img/           — фотографии JPG, на страницах чередуются через CSS
favicon.ico    — иконка
kak-vylozhit.html — как выложить на GitHub Pages и uCoz

GitHub Pages
------------
Загрузите содержимое этой папки в КОРЕНЬ репозитория
(файл index.html должен быть в корне, не во вложенной директории).
Settings → Pages → Deploy from a branch → / (root).

uCoz
----
Файловый менеджер → корень сайта.
Загрузите html, style.css, favicon.ico и папку img/.
В настройках сайта кодировка UTF-8.
Не прогоняйте страницы через визуальный редактор uCoz.

Локально
--------
Откройте index.html в браузере.

Ссылки внутри архива — относительные. Видео не встроены,
только гиперссылки на YouTube, Die Zeit и издания.
